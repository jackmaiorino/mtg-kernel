# Public prevention observation correction

The completed Gate-color diagnostic did not reverse either selected Gates/Affinity loss. A follow-up audit found a concrete observation defect: resolved Prismatic Strands shields were stored in `engine.active_replacements`, while `continuous_effects_public_v2` visited only attachments and `until_end_of_turn` effects. Every emitted `prevent_damage_from_color_mask` was zero. The feedforward V4 model could not distinguish a protected position from an otherwise identical unprotected position.

The pre-fix reproduction is preserved at commit `4877f86f`, with output in `E:/mtg-postboard-campaign-20260920/prevention-observation-diagnostic-001/reproduction.log`. Both physical seats had identical visible observations, legal menus and all thirteen native tensor arrays, yet the same five red damage left life 20 with the shield and 15 without. This is an information defect, not merely a questionable policy choice.

Read-only trace audit: `E:/mtg-postboard-campaign-20260920/strands-visibility-trace-audit-001/audit.json`. All games in the six preserved Gates/Affinity development traces were included. The g115/control/broader arms made 7/14/7 Strands cast selections, all on their own main phases. They cast again with an earlier same-turn shield on 3/6/2 occasions, all with zero prevention mask in their visible input. Exact repeated-color choices occurred 2/3/2 times. Pass was offered at every cast. Mean selected mass on the prior-shield casts was 99.9518%/99.9928%/99.99997%. These are selected cases, not population prevalence. A duplicate shield adds no prevention, but this alone does not prove every entire casting action dominated once other costs/triggers are considered. Lifetime is keyed by both turn counter and active player, not the counter alone.

Correction: the public effect producer appends one global EndOfTurn effect containing the union of current W/U/B/R/G shields. It checks exactly the same turn and active-player lifetime as the damage replacement. Duplicate installations, replacement IDs, source references and order do not affect the emitted row. No source is exposed: a publicly resolved shield remains public if its source subsequently moves to a hidden zone. Synthetic `PreventNextDamage` is outside this pool-card fix.

This repairs an existing, already typed prevention-mask field. It does not alter JSON schemas, tensor dimensions, Python encoding contracts, rules, reward, model or optimizer state. It DOES change observation values in affected positions for newly built runtimes, including the shared V2/V3/V4 consumers. Existing binaries, checkpoints, trace stores and completed measurements remain frozen. New builds/results must carry the correction's source/binary identity and must not be pooled with pre-fix measurements or described as unchanged deployment behavior.

Representation limitation: source-free global effects have no source/object edge, so the current encoding carries the mask in canonical state/action hash features; effect presence also contributes to the existing state count. There is no dedicated global prevention-color vector. This correction removes exact input aliasing but does not establish that g115 can use the information or that the encoding is sufficient for reliable strategy. A structured-feature successor is a separate possible learning experiment, not silently included here.
