# V4 search package and collection integration constraints

2026-09-22. Source audit for future evaluation integration, no route implemented and no formal launch. Keep exact existing Disabled package bytes/hashes and guards. AgentSearchPolicyV1 currently has Disabled and KernelNativeDescriptorV1 (phase1_agent_v1/package.rs:210); the old authority is not a V4 search authority. Add a separate strict descriptor carrying algorithm/version, model identity, numeric contract, sampling/key versions, public seed namespace and work limits. Metadata validation is separate from execution authorization.

Preserve three existing reject predicates: package.rs:456, phase1_bo3_collection_v1/mod.rs:253, phase1_bo3_learning_v1/preparation.rs:435. A new evaluation entry point may validate and load the explicit new descriptor; it must not weaken those existing APIs or pretend to be a Disabled package. Preserve registered decks, opening/play-draw, BO3 chooser semantics and sideboard policy across matched variants.

Critical recording constraint: RecordingPolicy::select_action_v1 at collection mod.rs:851-855 calls select_paired_with_scores_v1 and then BehaviorDistributionV1::hamilton_from_logits_v1(scores.logits,selected). Overriding selected with search while retaining this distribution would falsely attribute behavior probabilities. A separate evaluation record must carry actual deterministic selected action, root visit/value diagnostics, public seed/work census and search identity, without claiming ordinary-policy propensity. No native training capture or learning import of wrapped trajectories. If later teacher/distillation is proposed, it needs the monitor's actual-softmax/importance-weight contract and its own review.

Algorithm integration is conditional on sampler and core design/source acceptance. Fixed diagnostic replay can inspect action and timing changes first. Formal whole-match comparisons still need literature, declared powered gate, frozen seeds, guarded throughput qualification and committed outcomes. No playing strength, posterior accuracy or milestone is established by package compatibility.
