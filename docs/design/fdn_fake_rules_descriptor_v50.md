# Fake Your Own Death V50 rules descriptor

The separate Partial candidate now has a rooted, ordered printing descriptor.
It is preparation for public consumers, not a Full printing, model, sampler,
search or training admission. No existing meaning enum, vector, schema or profile
is rewritten. Native compilation and runtime qualification remain pending.

The exact existing printing selector verifies the real executable Instant,
`{1}{B}`, any-creature target, colors, mana value and installation recipe. The
descriptor records the actual capability and observed-at-runtime catalog identity.
No new catalog hash or printing ID is guessed.

The Instant root contains two ordered instructions: +2/+0 until end of turn,
then the separate gained dies ability until end of turn. Its nested death program
contains return of the original card tapped under its owner, then Treasure for
the creature's controller at death. The derived gained-ability root describes
that same ordered program. It is not a printed trigger on the target's card.
No executable capture-history index appears in the descriptor.

Incarnation annotations distinguish the battlefield grant recipient from the
original graveyard card. Tokens never return; a failed return still permits
Treasure. Distinct grants yield distinct triggers. Returning-Aura host choice is
untargeted and belongs to the card owner. These are rules semantics; the explicit
model-admitted flag remains false.

The selector binds schema, actual catalog and an immutable compiled-source
fingerprint. Root hashing retains the exact cost, card shape, installation recipe
and typed ordered instructions. Validation reconstructs the entire descriptor
and compares every field. The source fingerprint is cached once per process,
without game-state or dependency-function inputs.

All ten paid fixture groups construct and validate both roots for their genuine
printing, while requiring Partial capability and no model admission. They still
exercise paid mana, cast/target/actual engine execution and complete restores.
Those checks are written, uncompiled and unrun. Complete V50 public projections,
backend/Human clients, model representation and fair search/training remain open.

Source consultation found missing exclusions for extra rule descriptors and
missing direct death/color-protection callees in the producer fingerprint. The
printing selector now checks every current CardDef field, including alternate
cast forms, additional abilities, replacements and entry/combat rules. The
fingerprint now includes the actual trigger, death-capture and controlled-grant
implementations and shared return helpers. Runtime remains pending.
