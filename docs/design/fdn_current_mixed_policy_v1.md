Base: `4e20c0255f75064993df4a2ac40a57b070d7334b`. This is source preparation,
not a compiled model contract, trained policy, runtime qualification or engine
capability change. Registry, profiles, frozen encoders and search stay unchanged.

`current_mixed_policy_v1` owns separate V50 and V51 sessions and opaque decisions.
Each takes the genuine typed observation, original ordered action semantics and
complete private family binding. Every apply revalidates that original binding
and the regenerated numeric packet immediately before the real session step.
Snapshots retain private owner identity; owning restore advances generation and
the existing backend revision, so old decisions cannot execute after restore.

The numeric tree retains arrays, named schema fields, enum/category tokens and
all exact integer magnitudes. Node tags, UTF8 schema/category bytes and four
16-bit integer limbs are exactly representable in f32. Parent/sibling ordinals
also use four limbs; no 255-target or seven-trigger limit is introduced. Raw
physical references become first-occurrence roster ordinals, incarnations have
separate relationship ordinals, and effect timestamps use chronological ranks.
Presentation names/text, version/provenance hashes and prompt authority are not
features. Unknown history, generation or identifier shapes refuse explicitly.
Serialization is an internal typed-value visitor, not JSON byte/hash features.

Thin public root references are expanded through their existing typed meaning
producers. Full inherited meaning/fact records retain their ordered structure.
Exact baseline descriptors cover intrinsic land mana, ordinary vanilla/keyword
creatures, Llanowar mana, ordinary Bolt and Treasure's atomic mana ability.

Graveyard flashback alternative `{2}{U}`, each Draw1 for the controller, with
flashback's exile replacement on every physical stack departure. Its exact
immutable costs/program and all unrelated CardDef fields are authenticated.
These printing descriptors grant no permission or executable payment plan;
the original typed candidate and backend cast state authenticate the route.
The closed counter subset adds Counterspell, Essence Scatter, Refute and An
Offer You Can't Refuse with exact costs and spell-type filters. It represents
counter eligibility, physical/flashback/copy departure and nonrefunded costs;
Refute retains counter, draw, private discard order. Offer samples the target
spell controller before counter and rewards that controller independently of
counter success using the complete Treasure printing descriptor. Every other
counter/payment/mode recipe remains unsupported. Legacy compiled zone-only
counter guards remain explicitly distinct from Limited's protected-spell guard.
Every current CardDef field is either represented or excluded by that selector.
No raw executable EffectOp, private world or full static catalog enters tensors.

The new native network is an ordered tree recurrence with explicit input20 and
hidden16 dimensions, parent/previous-node connections and state/action/product
readout. It has its own source/catalog feature identity and parameter contract;
no predecessor checkpoint is accepted or automatically transferred. The public
forward returns one finite logit for each original action or an explicit error.
Deterministic fixture parameters demonstrate arithmetic only, not useful play.

Coverage remains intentionally incomplete: cards without a complete currently
available typed printing descriptor refuse `UnsupportedPrintedRoot(id)`.

not claimed model support. Ordinary nonbaseline spells such as Brainstorm,
unexpanded root forms and unknown reference shapes likewise refuse. This
prerequisite therefore does **not** claim complete current-catalog scoring.
Closing those concrete root/shape gaps is subsequent implementation work.
Frozen model identities and retained-world sampler/search refusals remain.
