# Guided search replay

Build and publish a recorded search walkthrough for three real decisions. The game remains paused while a separate search timeline follows actual simulations, previews hypothetical positions and updates root visits and values. Start with a readable root fan and the selected continuation; expose all simulations and branch choices progressively.

1. Add an optional observer to the existing V4 search, preserving its arithmetic, budgets, ordering and random draws. Capture contexts at selected decisions only, together with the existing simulation traces and node reports. Observer failure makes the capture incomplete while gameplay continues.
2. Export `mtg-kernel-viewer-recording/v2` with a validated `mtg-kernel-search-replay/v1` payload. Continue loading v1 fixtures. Join by the complete gameplay decision key, preserve node/action IDs and verify replayed visits and value sums against the existing root digest. Keep hypothetical boards separate from gameplay frames. Export public zones only for hypothetical worlds; exclude both sampled hands and unrevealed private action descriptions.
3. Add a deterministic search controller with play/pause, event and simulation stepping, seeking, speed selection and cancellation. Show the active path, evaluated continuation, value backup, evolving root statistics, policy priors and recorded selection scores. Label sampled worlds, actor perspective, scale and search termination accurately. Links can select a game decision and search event. Reduced motion, keyboard operation and narrow screens remain supported.
4. Acquire one complete illustrative self-play game, stopping at success within three attempts, 90 minutes and 2 GiB raw output. Reuse frozen weights, T512/depth64/stability halves off and the supported qualified CPU launcher. Preserve reservations, make a current three-host inventory and retain failures. No training, paid host or strength claim. Publish three annotated replay moments in a new immutable demo release; preserve the old pack.
5. Verify capture on/off primary parity, exact trace/root reconciliation, hidden-card redaction, broken references, legacy imports, transport cancellation and terminal behavior. Inspect desktop and 320 px layouts, watch the three real replays, measure seeking and playback, then review and merge the exact head. Verify Pages and bookmarked replay links before issue closure. Retain sealed evidence with an independent copy and cleanup receipts.

Implementation lives in the owned `codex/guided-search-replay` worktree branch. One issue and PR track this coherent release. Full arbitrary tree exploration and live search remain later extensions of the same recording boundary.
