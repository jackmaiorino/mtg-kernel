# Checked native P/T source repair

Base: `4e966b313062c509e96e284431ec34093ea3a50a`. This is source work only;
the Rust code and four new test groups have not been compiled or executed.

The actual engine has one axis-parameterized evaluator. It preserves the
existing layer predicates and order, accumulates in checked `i128`, and requires
the final value to fit the existing `i32` domain. Internal team, Bestow, Banner,
Aura and Standard count helpers use wide intermediates. Jodah retains its old
`i32::MAX` helper cap; this repair does not change that Standard policy. Existing
base-setting helper policies are likewise unchanged. No schema, counter width,
enum, catalog, profile or model admission changes.

V52/V53 current facts consume this query directly. V52/V57 observation ingress
checks it before inherited validators. Engine Step refuses an invalid current
battlefield without mutation; Advance records only the existing halt. Temporary
boost installation checks the proposed exact-incarnation additive result before
allocating its timestamp or inserting modifiers. The demonstrated genuine paid
Hatcher Prowess overflow therefore halts without installing the boost, drawing
the underlying Think Twice, or committing an SBA death. Execution sequences and
continuations stop on halt, and the ordinary resolver does not call a failed
leaf complete.

SBA checks the entire creature battlefield before a sweep and after Standard
copy refresh, uses the same checked result for toughness, and stops on error
before deaths/detachments/legend choices. Its production callers stop after a
halt rather than continuing trigger placement, activation publication or the
second combat wave. Ordinary in-range behavior follows the same predicates and
arithmetic; cancellation is evaluated before the final native conversion.

The active pure-Limited both-seat test bodies cover actual paid Hatcher and
Think Twice/Prowess at zero and the exact upper boundary, serialized replay of
the overflow, timestamp/modifier preservation, genuine retained counter
placement outside the native envelope with read-only Step/projection and
halt-only Advance/SBA, and explicit lower-bound/cancellation primitive operands.
Those arithmetic operands are not additional fictional paid printing claims.

This is not a complete preflight of every P/T-changing writer. Counter placement

The new battlefield sweeps add query work; no throughput claim is made.
