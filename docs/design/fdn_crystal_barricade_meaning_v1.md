Based on unregistered source0214c492. The separate v1 selector binds the actual
catalog hash and gameplay/targeting/prevention/definition/build producer files.
Default and Standard reject the live selector before definition lookup. Only
the executable Crystal Barricade with its actual1W, white artifact creature
Wall0/4, defender, and no spell, activated or triggered program is accepted.
The two printed static roots are named selectors, not engine enum ordinals.

Controller hexproof prevents opposing spells and abilities targeting the current
controller, permits self targeting, grants no object hexproof and rechecks at
resolution. Noncombat prevention reads the current effective creature and
controller, excludes this source, permits another source to protect it, leaves
combat/player damage unchanged and respects cannot-be-prevented. Full prevention
produces no committed damage, damage triggers or lifelink. Both rules require
the current front-face battlefield source with active printed abilities; owner,
original cast controller and tapped state do not constrain them. Departure,
suppression and control changes immediately update the continuous rule.

successor for overlapping consumable shields. This record describes scoped
implemented facts and that limitation, without claiming complete interaction
admission. Full-record reconstruction and strict unknown-field deserialization
reject changed identity, root or semantic facts. An artifact hash authenticates
the selected description, not a game's current state or execution.
