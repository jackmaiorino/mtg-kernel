# Complete FDN V76 owner, starting with Drakuseth: source design

Issue #110 still has 25 later-family owning refusals. Kaito V75 deliberately
rejects authorized printings at IDs 460 and above except its named complete
successors. Its own-hand projection fails at `kaito_observation_v75.rs`'s
`require_supported`; the outer session currently labels that failure
`ravenous_v51:InvalidDecisionRelation`. Removing the guard would publish
incomplete meanings. This design is preparation, with no new qualification,
catalog promotion, experiment or paid work.

The next complete family is Drakuseth, Maw of Flames, ID464. Its native attack
and one-to-three distinct target operations already exist, as do the exact
printing in `rules_meaning_drakuseth_v67.rs` and the current, cast, held,
target-selection and published facts in `drakuseth_public_v67.rs`. The existing
V67 selector requires Partial; a Full successor must preserve that historical
refusal rather than silently broadening V67's contract.

Implement one distinct FdnV76 observation, candidate set, sealed session owner,
current numeric entry, Human view and transport. Later families extend an
exhaustive typed LaterFamilyV76 enum and its exact validator, initially admitting
only Drakuseth. Each extension changes the source/checkpoint identity. Unknown
or incomplete families still refuse; an arbitrary JSON or raw EffectOp payload
cannot stand in for their facts. This avoids another owner, scope and transport
for every remaining family. Compose the complete inherited
V75 facts, family projections and eighteen-counter rosters with validated
Drakuseth facts. Give compatibility layouts distinct V76 schemas. Existing V75
entry points continue to refuse Drakuseth. Private compatibility helpers may
admit this exact family only for the new owner, after their complete original
native state and observation checks. Known authorized identities and genuinely
public captured history select scope; unseen opposing identities never do.

The sealed FdnV76 owner binds the genuine session, issued origin, revision, physical
decision, substep and exact original native action vector. Private native
candidates retain executable bindings. Public candidate annotations describe
the actual selected slots and remaining distinct choices, including mandatory
first target and optional second/third targets. Damage belongs to the original
positions: four for slot zero, three for each later slot. Never sort or compress
targets after one becomes illegal. Finish choices and target references carry
no executable authority. Applying and restoring use the existing original
backend action mapping and revision rules.

The numeric entry expands the exact new ordinary printing, full ordered attack
meaning and authenticated family facts. Canonicalize paired object/incarnation
references together, including V67's `object`/`generation` target rows, without
publishing raw arena IDs or making semantic identity depend on opaque hashes.
Retain original captured controller/source and target incarnation, optional
target counts, current legality and current source characteristics where
authorized. Historical declaration counts are descriptive: native history has
no unique attack-occurrence join, so neither an execution receipt nor a
completion claim can be reconstructed from that count.

Qualification uses actual paid casts and attacks for both seats, the full
one/two/three-target menu, optional early finish, duplicate refusal, target
departure/reentry and all-target illegality, source departure/control changes,
current replacement/protection outcomes, held and choosing-target restore,
stale/foreign binding refusal, original ordered-action parity and finite model
forwards. Independent hidden worlds must yield identical actor packets for
identical authorized evidence. Human/transport views preserve the complete
candidate set and reject forged or stale packets. Reuse compatible native
mechanic tests; add checks only for the missing composition risks.

An actual engine prerequisite remains: the existing Drakuseth regression
deliberately refuses Crystal Barricade combined with finite prevention. Its
positional damage is one simultaneous batch, so sequential DealDamage lowering
would change the rules. Extend the existing owned batch continuation to mixed
player/permanent recipients and authenticate Drakuseth's original source facts
through departure/reentry before claiming that composition. Current batch
choices assume object recipients, and historical-source resolution does not
yet recognize a Drakuseth producer. Preserve the prior refusal test until its
replacement proves the actual mixed batch, source LKI, ordering and restoration.

After native qualification, coordinate Full promotion, append-only catalog and
live store profile integration serially with the parent FDN branch. Recheck the
full-pool audit and actual default branch. Registration, source preparation or
the new owner alone does not establish full Foundations, fair search, training
or DraftZero acceptance. Current reservations and Claude's research ownership
remain binding throughout.
