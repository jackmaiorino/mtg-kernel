# Current model thin-root transport repair

Source-only successor of clean `4e966b313062c509e96e284431ec34093ea3a50a`.

The inherited family union publishes catalog roots for Authority, Employment, Cerberus, Temporal Manipulation and Juggernaut independently of the current board. Its actual records carry an optional index, a fixed ordinal, or no index. The model adapter previously asked every one for a `root` field that those producers do not emit, refusing even an unrelated land-only packet.

`expand_thin` now decodes the actual five public producer record types and uses only their exact emitted selector mappings. Authority null and zero select its replacement and trigger respectively. Cerberus zero/one select its untap restriction and trigger zero. Juggernaut zero/one select its two combat rules. Temporal accepts only zero; Employment has a sole printed spell. A whole-record serialization comparison requires explicit null and rejects unknown fields. The selected immutable meaning is rederived and its digest must match the original record before expansion. Hashes never choose roots. Existing other meanings, normalization, native candidates, owning bindings and protocols are unchanged.

Two new Rust fixture bodies traverse all eight actual catalog rows through V50/V51/V52/V57 model owners for both seats. They check canonical root selection and changed index/null, erased selector, digest and extra-field refusals without mutating the actor owner. Genuine casts of all five families tap actual lands, consume mana, bind Employment's real target, resolve, and encode. Each step compares original native-menu execution, restores its model owner, refuses the stale decision and reapplies a fresh one. Original negative test bodies remain intact.

Observed validation: pinned `cargo +1.94.1 fmt --all`, `git diff --check`, source-shape/static API checks and 72 Python Limited deck/booster tests pass. All Rust is uncompiled and unrun. No native, network, GPU, profile/catalog, Full, model-completeness, sampler, search or strength qualification is claimed.
