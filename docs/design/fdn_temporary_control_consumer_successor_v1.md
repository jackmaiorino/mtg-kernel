# Temporary control consumer successor preparation

Involuntary Employment source introduces a resolved public current-turn control effect. Its creature target menu and actions fit existing engine contracts; its future control reversion does not fit the frozen continuous-effect projection. A successor must expose each exact public battlefield incarnation, the controlling and underlying players, application timestamp, and end-of-current-turn duration. It must distinguish ownership from control and preserve ordered overlapping records. Departed objects cannot expose a future control change on a newer incarnation. The source and current recipients are public; library/hand identities and privileged snapshot hashes are not model features.

V1/V2/V5/V6/V8 and derived V9 observations explicitly refuse the new pending/stacked printed operation and its active records. Frozen action enums, tensors, schemas, profile tuples and weights remain fixed. Any successor must carry its own catalog/source/schema identities, include reversion semantics in its feature vocabulary, qualify Human display and session/native restore, and qualify a matching model before admission. A target-only AnyTarget successor does not satisfy this control contract. No new consumer version number or generated identity is invented here.

RulesMeaning must describe GainControl(You, exact targeted creature, EndOfTurn), the subsequent untap and temporary haste, and independent mandatory Treasure creation conditioned on spell resolution. General Layer 2 control dependencies or durations beyond the current cleanup require a separate engine successor. This design is source preparation, not Full coverage, a model migration or playing-strength evidence.
