# Restricted continuation sharing

Arm B uses `SearchOptions.sharing=true`; every existing entrypoint defaults to false. It pools selection guidance at the endpoint of an uninterrupted run of at least two focal basic-land mana activations. It retains the original history tree, one-node expansion, independent sampled worlds, real terminal rollouts, and each incoming node's natural backup counts. Frozen execution still needs eight actual backups on its own edge and uses its own outcome mean. A pooled win is empirical evidence, never a solved win or a replayed terminal sample.

The first contract covers ordinary Plains, Island, Swamp, Mountain and Forest at priority in Main1/Main2. Every battlefield permanent must be an unmodified face-up basic land. The guard rejects pending cast, activation, target, effect, discard, copy, land-play and trigger contexts; stack objects, replacements, continuous effects, initiative/monarch, nonempty public graveyard/exile/command, and restricted mana. It never serializes private engine state or reads hidden definitions. Face-down status is checked before a battlefield definition is read. An intervening transition, including a forced action or an opponent action without a policy call, breaks the run.

The engine's `activate_mana_ability_for` applies a basic source's pure tap-and-add program, records its source-local ability use, resets priority passes, increments the activation count, and records the same activator. With the guard, no permanent or public-zone trigger source or replacement can make their order matter. No zone change, card reveal, random draw, opponent policy call, or focal rollout-policy call occurs within the run. Taps of distinct sources commute: source-local tap/use updates and additions to ordinary color pools leave the same decision after every source has been activated once. Engine event order differs, but these tap/mana-add events have no remaining gameplay reader under this contract.

Identity retains the exact pre-run incoming history key, pre-run actor information, sorted exact tap action bytes, final complete raw actor observation and live menu, canonical action binding, physical search depth, and root-relative transition position. Only physical decision/step counters and the derived projection hash are omitted from the raw view. Raw object handles, incarnations, timestamps, knowledge, ordered lists and surface context stay exact. Pools are scoped to one search with its fixed world prior, checkpoint, seeds, rollout policy, depth limit and runtime profile. Normalization stops at the endpoint: a non-tap action starts ordinary independent history again. Pending decisions always reject reuse, so absent accumulated targets in the viewer snapshot cannot merge them.

Each natural simulation supplies its unique attempted-simulation ID. A pool credits at most one edge once for that ID and refuses repeated or older IDs, including cyclic revisits on another edge. Truncated, faulty, rejected and nonnatural attempts supply no pool credit. Pool guidance is UCT over these real samples; it creates no incoming backup or execution support. The implementation bounds pool allocation to an estimated 64 MiB and duplicate-view diagnostics to 65,536 hash entries, then retains existing entries without weakening identity.

Diagnostics distinguish duplicate visible views, unproven duplicates, eligible endpoints, cross-history endpoints, guidance hits and changed selections, fresh samples, duplicate-sample and capacity refusals, guard reasons, estimated memory and key/backup time. PR241 already removes some identical-copy tap permutations; different-color basic taps remain distinct legal choices. Zero useful hits is a negative result for this restricted contract. It neither supports nor refutes general transposition sharing, hidden-world grouping, or playing-strength claims.
