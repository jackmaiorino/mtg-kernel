Source inspected: codex/public-stack-features-v1 at 5e49f1a3. Read-only audit, no training or gate. Finding: the grouped terminal objective does not implement GRPO's per-episode inverse-length factor or per-cell standard-deviation division. It does divide the complete update by its physical-decision group count, which defines a decision-weighted objective and a batch-dependent gradient scale. Removing that denominator would change the objective scale and is not justified by analogy alone.

`experimental_burn_net8_packed_v1/training.rs:2192` computes the grouped terminal loss. For update size G, substeps s within physical decision g, detached current value V, terminal return R and committed cell baseline c, the policy term is `-(1/G) sum_g [(R_g - stopgrad(V_g) - c_g) sum_s log pi(a_gs)]`. Value loss is `value_coefficient/G * sum_g (V_g-R_g)^2`. Substep log probabilities are summed, not averaged by substep count. That sum is the joint-action factorization, not an episode length correction.

`experimental_burn_net8_packed_v1/bridge.rs:653` sets `total_group_count = groups.len()` once for the complete update. Lines 704-711 pass that same denominator to each chunk. Chunking therefore does not overweight a shorter last chunk. The GAE/coefficient sibling at training.rs:2267 uses supplied constant advantages and the same grouped normalization; this inspection does not establish how every upstream caller constructs those advantages.

`native_policy_baseline_state_v4.rs:1-10,92-106,182-214` defines a strictly lagged, decision-weighted per-opponent/per-seat residual mean and EMA with beta .05. There is no per-cell standard-deviation state or division in this baseline path. `native_trainer_v1.rs:2773` resolves committed baseline bits before constructing the update, and collects successor observations after the update at line2875. This is objective version terminal_reinforce_value/v4; it is distinct from V4 observation features. Presence in the source does not establish that a particular g115 continuation enabled that objective.

The remaining modeling question is decision weighting. With one physical group in one episode and three in another, equal per-group terms assign total weights 1/4 and 3/4. There is no separate division by each episode's length. Compared with an episodic sum divided by episode count, dividing by random G also makes the scale depend on the sampled batch length. We cannot declare an unbiased episodic-return estimator, a harmful length preference, or a causal explanation of retained128 from this source audit. The intended estimand and empirical association between G, return and gradient would need a separate bounded analysis before an objective change.
