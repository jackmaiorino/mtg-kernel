# Proposed V4 information-set search core

2026-09-22. Engineering design draft for independent review, not a measurement launch or candidate promotion. Literature: collab/lit/20260922-v4-sampling-validity.md (MTG ensemble determinization and ISMCTS). The sources motivate pooling statistics over observable decision contexts; they do not validate this sampler, eliminate strategy fusion, or predict gains.

Algorithm: separate crate-private V4 route, plain frozen V4 evaluator only. Each simulation starts a newly sampled root clone from the reviewed whole-object sampler. Tree nodes use the V4 actor-visible key including remaining decision depth, ordered action semantics and V7 historical sources. One shared tree per root; no true-state hash, private identity, or environment RNG enters selection or seed derivation. Simulation seeds derive from a new domain, public root key, explicit experiment seed and simulation index. Fixed simulation/depth/transition limits, no wall-clock stopping. Cached priors are valid only under equal keys and exact legal counts. Preserve deterministic iteration and tie-breaking.

Selection: reuse tested integer prior quantization/UCB bonus arithmetic, but new V4 session/key/consume wiring. Expand unvisited edges in descending prior then action index; thereafter maximize root-perspective mean plus prior-scaled exploration at root-player nodes and minimize mean minus exploration at opponent nodes. Final root action: most visits, then root-perspective mean, then index. Require budget sufficient to visit every root action once, force that initial coverage deterministically, and report actual completed simulations, transitions, root visits and leaf census. Any clone/key/binding/step/halted error aborts the entire search with no selected action, no resampling or partial-tree fallback.

Leaf and terminal contract: fresh V4 encoder per live leaf; evaluate only on a live decision. Natural terminal uses exact root-perspective win/draw/loss. A session Truncated terminal aborts with a named error; never invent a live encoding or substitute a privileged-state key. Depth/budget cutoffs happen at live decisions. Candidate value rule for review: finite raw value is clipped symmetrically to [-1,1], preserving zero as draw, then converted to the integer terminal scale with deterministic rounding and actor-to-root sign. This is explicit clipping, not an analytic model-output bound or min-max calibration. Count low/high clips and record extrema. Do not reuse the old calibrated min-max mapping without justification: shifting its midpoint can change draw semantics. Verify g115 target semantics before ratifying this rule; reject nonfinite values.

Acceptance before playing integration: sampler/source review complete; both seats; natural/halted/truncated and live-cutoff branches; legal root action; accounting conservation; same seed exact diagnostics; root hidden-arrangement invariance where supported; finite value/clip controls; second-node consume; actual g115 two archived roots and certificate acceptance fixtures. Certificates constrain known forced-line outcomes, not that a bounded search must solve every provable tree. Report action changes and measured cost without strength inference. Separate new strict descriptor/collector route keeps all three existing disabled-search guards and training exclusion intact.

Next measurement design remains separate: powered tactical-fix and whole-match non-regression estimands, declared n/effect from measured endpoint vectors, literature note, independent review and fresh guarded useful-throughput qualification. No CP7 selection, no paid compute, no milestone claim. This design deliberately does not claim a calibrated hidden-state belief distribution, opponent inference, sideboard knowledge or solved strategy fusion.
