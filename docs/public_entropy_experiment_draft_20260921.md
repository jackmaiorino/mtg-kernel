# Bounded entropy continuation comparison: preparation draft

Status: design fixed for preparation on September 21 after engineering qualification; the historical filename is retained. The preparer freezes both replicas' seeds, coefficient and gates before any new outcome is observed. Measured allocation and analysis implementation must be bound before substantial launch. This is a single controlled learning question, not a hyperparameter sweep or a broad campaign.

Question: can optional entropy regularization improve repeatable meta-wide terminal BO3 performance over otherwise identical g115 continuation? The fixed-checkpoint audit motivates this hypothesis but does not establish harmful overconfidence. The fixed treatment is beta=0.05, chosen as one bounded exploration hypothesis after analytic gradient, normalization and real optimizer qualification, not tuned on win-rate prefixes. This is not an optimal-coefficient claim. A reference-policy anchor is an alternative, but can preserve existing errors. A KL penalty to the identical current behavior policy starts with zero gradient in our single accumulated-update architecture; merely adding PPO clipping around ratio one would not constrain the subsequent Adam step. These are implementation-specific reasons to test a nonzero entropy gradient first, not claims that PPO or anchoring are generally ineffective.

Proposed learning comparison: two independent, fully predeclared schedule-seed replicas; in each, beta0 versus beta0.05, both starting from untouched g115 and its complete optimizer. Use 200 synchronous updates of ten natural games per arm: 8,000 training games total. Retain the existing registered deck/pre-postboard/seat/opponent schedule and terminal GAE, but assign fresh environment seeds disjoint from prior training/evaluation. Disable the public cost/prevention projections in both arms. No stack, card-face, reward, opening, sideboard, opponent-pool, learning-rate or optimizer changes. Final update199 only; no intermediate endpoint selection.

Proposed measurement: a balanced eight-archetype panel, all64 ordered matchups, eight environment seeds per matchup and both physical candidate seats, with game-one chooser balanced. This is 1,024 BO3 per endpoint, comparing untouched g115, control and entropy separately for each replica: 6,144 BO3 total. Use fresh paired seeds across all three endpoints within each replica; replica panels independent. Equal matchup weight avoids carrying the previous prevention experiment's Gates-heavy primary weighting into a general optimizer test. Preserve fixed opponents, terminal outcomes and original evaluation semantics. Report own-deck, ordered-matchup, seat/start and game-one limitations alongside the overall effect.

Proposed fixed advancement gate for each replica: at least20 additional BO3 wins over its matched control and a paired95% interval strictly above zero; nonnegative BO3 count versus untouched g115; game-one win-rate difference lower bound greater than -0.05 versus both control and g115. Both independent replicas must pass before treating the intervention as a reproducible development improvement.
