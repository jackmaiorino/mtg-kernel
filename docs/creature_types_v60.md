# Pinned creature-type primitive V60

This prepares a shared legal choice domain and matching query for the frozen FDN Secluded Courtyard (267) and Banner of Kinship (127). It registers neither card and changes no mana, static effect, action, policy, owner, catalog, or support permissions.

The official [Wizards rules page](https://magic.wizards.com/en/rules) linked [the September 25, 2026 Comprehensive Rules TXT](https://media.wizards.com/2026/downloads/MagicCompRules%2020260925.txt) when checked October 15, 2026. CR 205.3m supplies 323 one-word names and separately names Time Lord. The factual input in `data/rules/creature_types_v60.json` records all 324 names, the effective/retrieval dates, authority, source URLs, original byte count, full-document SHA-256, and clause UTF-8 SHA-256. The full rules document is not copied into this repository.

The domain freezes the one-word names in the actual source order and appends Time Lord as index 323. Every index is explicit. A future rules list requires a new domain version rather than renumbering V60. Time Lord, Assembly-Worker, C’tan, and Shi’ar have explicit canonical spellings. Parsing accepts those exact names. Native uppercase aliases map explicitly to their canonical type without altering any existing `Subtype` discriminant or changing its historical `CREATURE_TYPES` list. All 154 current native variants are classified, including 33 noncreature variants and six duplicate aliases. The resulting 115 distinct represented creature types are a subset of the complete choice domain.

`CreatureTypeChoiceV60` serializes a closed canonical enum, schema, and pinned domain digest. Invalid identities, unknown fields, numeric enum values, malformed names, and noncreature names refuse deserialization. Choices require no game state, library, deck, visible card, hidden card, or lookup through a pool. This is a standalone public value, not a new field in existing engine or owner snapshots.

`matches_effective_creature` reads the actual object's effective native subtype IDs and effective creature card type, canonicalizes the entire subtype set, and rejects unknown native IDs. It separately carries printed changeling's all-legal-types meaning, subject to face-down characteristics and active layer 4 type replacements. Layer 6 ability removal alone does not undo the earlier type contribution. Ordinary matching never infers all-types from a large finite set or card names. The source query changes no state and obtains no other object from a player's hidden zones. Its caller must already have authority to inspect the object and must separately enforce zones, controllers, current incarnations, source identity, spell forms, and visibility. It does not authorize a future policy consumer to expose hidden characteristics.

The query follows the current native effective-characteristic providers. Animations, including active Soulstone and older animation records overlapped by later type replacements, explicitly return `UnsupportedAnimationTypeComposition`. The native animation representation currently has only a finite subtype slice and its query does not expose a timestamp-composed universal-set fact. Treating that slice as all legal types would guess semantics. This lane does not repair those providers, expand their finite representation, or introduce type-changing effects. A future animation representation must carry explicit all-types meaning and compose it with replacement timestamps. Courtyard's chosen-type mana restriction and Banner's entering count, fellowship counter type, continuous boost, choices, object-state persistence, and consumer reach remain separate implementation work.

Source unit cases cover domain closure, all pinned indices and native IDs, aliases, strict public serialization, actual ordinary Serpent matching, unrepresented Time Lord, actual Masked Vandal changeling across all legal choices, face-down replacement, native subtype replacement, invalid data, animation-composition refusal, and snapshot/JSON restores. Native fixtures are source assertions, not executed evidence in this lane. The small Python checker validates the enum/input/native mapping offline and can additionally verify the exact original Wizards TXT with `--rules-file`. Pinned rustfmt, the Python source audit, and diff checks are allowed here; no Rust compilation or native execution is claimed.
