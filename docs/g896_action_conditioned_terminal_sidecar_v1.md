## Question

The current policy value head, selective search, independent critics, terminal-rollout search, and the T32768 teacher have not ranked sibling actions with a repeatable natural-terminal advantage. The newest screen also showed that search visit share and estimated value advantage did not predict realized continuation gains. Test one untried structural alternative: can a small action-conditioned model trained only on natural terminal outcomes rank a state and a specific legal action better than the plain g896 policy and an action-label-permuted control?

## Fixed model and supervision

- Freeze g896 as the policy that generates roots and plays every continuation after the forced first action.
- Use no CP7 data, human games, heuristic evaluator, search score, or intermediate reward as a target.
- The only target is the final natural win, draw, or loss from the root actor's perspective, encoded exactly as win `+1`, draw `0`, and loss `-1`. For the published teacher records this is exactly `g896_score - 1`.
- Freeze the g896 encoders. Q-arm consumes the existing 64-float state embedding and 64-float action embedding, then uses the policy scorer's exact `128 -> 64 -> 1` tanh head shape with fresh parameters.
- C-arm is capacity- and data-matched to Q, but a predeclared derangement within each root assigns each terminal target to a different candidate action embedding during training. State embeddings, action-embedding multisets, targets, optimizer budget, and initialization seeds remain identical. Evaluation uses the real action embeddings. This is a negative control for correct action-to-outcome binding.
- PLAIN: the frozen g896 sampled action from the authenticated root episode.
- Keep the policy frozen. This design trains selectors only and cannot change g896.

## Phase 0, excluded preflight

Reconstruct the 64 published teacher-screen roots without modifying the formal evidence. Replay each stored episode prefix to the recorded semantic root, re-tensorize both recorded forced actions, and verify the identities and natural W/L/D fields of all 4,096 already published continuation records. Phase 0 does not rerun those games or create replacement outcomes. It materializes their fixed targets, trains Q and C twice from the same declared seeds, and requires byte-identical datasets, derangements, split records, model outputs, and summaries. A synthetic fixture with an action-specific terminal signal must be learned by Q and not by C. Real-data outputs need only be finite and deterministic. This phase may diagnose feasibility and code defects only. Its revealed roots cannot pass a selector gate, choose a hyperparameter, or authorize training a descendant.

Both arms use three fixed initialization seeds and average their predictions. There is no seed selection. The sidecar is exactly `Linear(128,64)`, tanh, then `Linear(64,1)` with no output activation. Each member trains on the per-root-action mean terminal score with equal root-action weight, MSE with mean reduction, and AdamW at learning rate `1e-3`, betas `0.9/0.999`, epsilon `1e-8`, weight decay `1e-4`, and AMSGrad disabled. Weight matrices use PyTorch Xavier uniform initialization and biases use uniform `[-0.01,0.01]`, from a CPU generator seeded with the member seed. Rows remain in ascending root and action-index order, with no shuffle. Batch size is 256 for exactly 20 epochs, with the final partial batch retained. No clipping, grid search, or early stopping.

For the 64 published roots, split within each physical seat by sorting the SHA-256 KDF of seed 971303 and semantic-root SHA-256, then take exactly 24 train, 4 validation, and 4 test roots per seat. Both actions from one root stay together. The two-action C control swaps the two action embeddings within every training root. Validation and test always use the real action embeddings.

The synthetic fixture has 256 roots with zero state embeddings and four action embeddings whose only nonzero coordinate is respectively `-1`, `-1/3`, `+1/3`, and `+1`; that coordinate is also the target. The synthetic C assignment cycles through all nine four-item derangements with its starting offset derived from seed 971304. Use the first 192 roots for training and the last 64 for testing. The fixture passes only if the three-member Q ensemble test MSE is at most `0.10` and `MSE_C - MSE_Q` is at least `0.20`. If the synthetic binding fixture fails, real-data outputs are nonfinite, or reconstruction is not exact, stop for redesign.

## Phase 1, fresh corpus and selector screen

1. Acquire exactly 1,024 fresh roots, 512 per designated g896 physical seat, from at most 2,048 scheduled g896-versus-g896 episodes per seat. Both actors use the frozen g896 checkpoint with seat-local policy ordinals and independently derived controller bases. Scan each complete natural-terminal episode and choose exactly one eligible decision for the designated seat by seed-derived reservoir sampling across the full episode. Eligibility is substep 0 of 1 with 2 through 16 exact legal actions. Natural episodes with no eligible decision are recorded and skipped; exhausting either seat cap classifies the corpus `INFEASIBLE`.
2. At each root, form a candidate set containing PLAIN plus up to three distinct alternatives sampled without replacement from the other legal actions by a predeclared KDF. Run eight matched natural-terminal continuation seeds per candidate action, for at most 32,768 corpus games. A halt, truncation, illegal action, missing terminal, or seed mismatch invalidates the corpus.
3. Split by environment root before training with exact seat-stratified counts: 716 train, 154 validation, and 154 untouched test. Both actions and all continuation seeds from one root stay in one split.
4. Train the fixed three-member Q and C ensembles. Require Q to beat its fitted training-split constant baseline on the untouched test split with a root-paired bootstrap interval above zero. Require Q's untouched-test MSE to be strictly lower than C's with a root-paired bootstrap lower endpoint above zero for `MSE_C - MSE_Q`.
5. On 256 additional fresh roots, construct the same PLAIN-plus-up-to-three-alternatives candidate set, then let Q, C, and PLAIN each select one action from that set. Evaluate the union of distinct selected actions with 32 matched natural-terminal continuations per root. The selector screen is valid only if every root and continuation is complete and the predeclared compute and artifact caps hold.

Phase 1 is one formal measurement with crash-consistent stages. Rust first publishes the corpus embeddings and outcomes. Python freezes the split, trains Q and C, and applies the untouched-test loss gates. A failed test-loss gate stops without acquiring selector outcomes. After a pass, Rust publishes 128 additional roots per seat from at most 512 scheduled episodes per seat. Python chooses Q and C actions, breaking exact score ties by lower flat action index. Rust then replays each published episode prefix, verifies the semantic root and candidate order, and evaluates the sorted union of PLAIN, Q, and C actions. No interim corpus, model, or selector outcome may change a seed, cap, model, gate, or tie rule.

CPU root acquisition runs fixed ascending episode ordinals in waves of at most 24. Every started wave finishes and is recorded. If a seat quota is reached inside a wave, later completed episodes in that same wave are recorded but cannot contribute a root. No episode beyond the per-seat cap is scheduled. Root acquisition indices follow physical seat order `p0`, then `p1`, and ascending episode ordinal among retained roots.

Every stage is written to a new directory. The trained-model artifact records the design and corpus-file SHA-256s. The selection artifact records the design plus selector-root and model-file SHA-256s. The selector-outcome artifact records the design plus selector-root, selection, and model-file SHA-256s. The analyzer rereads all four files and requires every binding before it reads outcomes.

Every KDF is SHA-256 over its listed ASCII domain, one zero byte, the declared seed as little-endian `u64`, then the listed fixed-width fields; a derived `u64` is the first eight digest bytes in little-endian order. Episode domains use physical seat `u8` then episode ordinal `u32`. Controller-base domains use episode seed `u64` then actor seat `u8`; mask the derived value to its lower 63 bits before passing it to the unchanged production g896 action-seed derivation. Reservoir domains use episode seed `u64` then the one-based eligible ordinal `u32`, replacing the retained root exactly when derived `u64 mod ordinal` is zero. Candidate domains use semantic-root raw 32 bytes then action index `u32`; rank non-PLAIN actions by full digest then index and take the first three. Continuation domains use semantic-root raw 32 bytes, continuation index `u16`, then actor seat `u8`, with the same lower-63-bit controller-base conversion. Split domains use semantic-root raw 32 bytes. Derangement domains use semantic-root raw 32 bytes and select by derived `u64 mod !n` from lexicographically ordered fixed-point-free permutations of `0..n`, where `n` is the candidate count. Corpus uses seeds 971310 through 971315 and selector uses 971320 through 971323 with separate domain names ending in the seed's declared role.

The untouched-test constant is the equal-row mean target fitted only on the 716-root training split. Test improvements are `MSE_constant - MSE_Q` and `MSE_C - MSE_Q`. Their 100,000-replicate intervals resample whole roots independently inside the two 77-root seat strata. Q must have a strictly positive lower endpoint for both improvements before selector acquisition. Selector action scores are the arithmetic mean of the three member outputs. The 256-root screen always accounts for 8,192 outcomes per arm, reusing the same root-action continuation when arms chose the same action. A 10 percent action-change gate therefore requires at least 26 roots.

## Frozen advancement gates

Q advances only if all conditions pass on the 256-root selector screen:

1. Q minus PLAIN total delta is at least 328 half-points, equivalent to a 2 percentage point minimum over 8,192 continuations per selector arm.
2. The paired whole-root bootstrap lower endpoint for Q minus PLAIN is strictly above zero.
3. Q minus PLAIN is nonnegative in both physical seats and in each `decision_kind` stratum with at least 16 roots. Smaller strata are pooled into `other` using root metadata before continuation outcomes are read.
4. Q minus C is positive overall and nonnegative in both seats. This is the action-binding check.
5. Q selects a different effective action from PLAIN on at least 10 percent of eligible roots. Below that level, the screen is classified low leverage even if noisy outcome gates appear favorable.

Every interval uses 100,000 whole-root bootstrap replicates with nearest-rank 2.5 and 97.5 percent endpoints. Roots are resampled independently within the two fixed 128-root physical-seat strata for the selector screen and the two fixed 77-root seat strata for the untouched test. The test-loss bootstrap uses seed 971316 and the selector bootstrap uses 971324.

Both bootstraps use `splitmix64-counter-modulo-stratified-whole-root/v1`. In row-major replicate order, counters start at 1. Each draw state is `seed + 0x9e3779b97f4a7c15 * counter` modulo `2^64`, followed by the standard SplitMix64 finalizer with multipliers `0xbf58476d1ce4e5b9` and `0x94d049bb133111eb`. The mixed value modulo the seat-stratum size selects a root. Draws for `p0` precede draws for `p1` within every replicate. The test statistic is the resampled equal-row MSE improvement. The selector statistic is the resampled total paired Q-minus-PLAIN half-point delta.

Any failed gate closes this exact Q configuration. A pass authorizes only a disjoint confirmation design. It does not authorize policy training, native promotion, or CP7.
