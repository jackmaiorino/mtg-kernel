# D3 whole-match gate power planning

No new games or training. All ten historical control endpoints are retained. Input is the hash-verified BO3 endpoint array documented in g115_d3_preparation_20260923.md. There are64 matchup strata,8 independent seed blocks per stratum and2 paired candidate seats per block:1,024 BO3 outcomes per arm. Historic control-minus-g115 paired sample SE is0.7382..0.8664pp. This is fixed-checkpoint inference planning, not independent-training-run evidence. Between-training-run s=0.76pp is reserved for D4.

Proposed full statistical gate: candidate net wins over baseline >=21/1024 (2.05078125pp), AND the paired stratified percentile-bootstrap2.5% lower bound is strictly positive. One primary contrast; deck/seat tables are descriptive. No all-replications-pass or tactical surrogate gate. Engineering validity is a prerequisite; the powers below are conditional on complete, valid measurement, not an estimate of infrastructure reliability.

Each seed block contributes the two-seat sum of paired binary differences in {-2,-1,0,1,2}. Bootstrap draws eight blocks within each of64 strata, keeping seats and arms paired. The exact conditional bootstrap distribution is the convolution of64 five-category polynomials, each raised to the eighth power, computed with4096-point FFT. Arithmetic checks cover constantzero, constantpositive and independently computed binomial quantiles. "Exact" refers to enumerating the conditional resampling distribution numerically; percentile-bootstrap population coverage remains approximate, especially with eight blocks per stratum.

For each of10 observed endpoint comparisons, a common exponential tilt of within-stratum empirical probabilities calibrates the requested population mean while preserving integer outcomes. Sensitivity further weights each paired net-win category k by2^abs(k), then recalibrates the mean. This raises disagreement within observed support. Historical sample SE uses ddof1; empirical-law variance uses ddof0, initially7/8 of sample variance. This finite-support plug-in assumption is disclosed rather than silently treating the smaller SE as an observed improvement. The sensitivity case reaches paired SE0.978pp at3pp and0.998pp at the null. It does not bound a novel search policy's variance or invent outcomes absent from historical support.

Each of160 cases uses2,000 independent simulated panels,320,000 planning panels total, under fixed per-case seeds. The entire integer-plus-bootstrap rule is evaluated on each. This is not80%-powered for a true2pp gain: a gate requiring an observed2pp gain has roughly50% power at its own threshold. The reviewer must assess this and the unbounded search-discordance extrapolation before launch. A failed gate does not prove zero effect or rule out gains smaller than the declared MDE.
