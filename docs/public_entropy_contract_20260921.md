# Optional grouped-GAE entropy term

The completed fixed-input audit found 64-70% of genuine choices had at least 99% top-action probability, and the better focal endpoint in each of two fixed pairs was less concentrated. This is an association, not proof that entropy improves play. The prevention-input ablation found small direct effects on 95 sampled exposed rows. The next isolated implementation enables an entropy intervention without changing observation, opponent mix, terminal rewards, GAE, Adam, collection order or the sampler. No experiment coefficient, new training panel or strength claim is selected by this engineering contract.

For a batch of N physical decision groups, retain the existing joint selected log-probability times normalized terminal-GAE advantage and first-substep value loss. Add `-beta / N * sum_s H(softmax(logits_s))` over the observed legal-action substeps of those groups. Entropy uses the differentiable float softmax already underlying the learner's policy loss, not the quantized execution sampler. This is a local on-policy entropy surrogate at the observed autoregressive prefixes, not an exact traversal of all possible macro prefixes, PPO clipping, a reference-policy anchor or magnetic mirror descent. Forced one-action menus contribute zero. Padded actions have zero probability; all chunks use the same full-batch group denominator and update Adam only once after accumulation.

`entropy_coefficient` defaults to zero and is omitted from serialized configs when zero, preserving all prior scientific config hashes. Nonzero finite values in [0,1] enter the config/checkpoint identity. The zero path directly executes the old loss without extra tensor operations. Inference scoring does not use the coefficient; it loads the actual learned parameters bound to the config. Old frozen binaries and results remain untouched.
