# MTGO DXGI visible-frame candidate v1

This standalone Windows package captures the foreground MTGO client using DXGI Desktop Duplication. The primary capture path does not use direct-window capture, accessibility enumeration, process memory, network inspection, client files other than the signed executable identity, hooks, injection, or keyboard input. Its mouse actuator is isolated in `src/actuator.rs` and is unreachable in the current production build because every exact production ratification root remains empty.

The project owner reports that Daybreak's written visible-only permission now covers both League and Challenge play on the approved main account, subject to the same no-hidden-information, no-reverse-engineering, and no-cheating limits. This expands the intended competitive scope, but it does not populate a production root. The exact exported correspondence bytes and approved account alias must still pass the existing local review importer and be intentionally bound by a separate reviewed source change before any live authority can exist.

Both commands read no MTGO process state or private correspondence, capture no pixels, score no actions, send no input, and grant no authority. Run them with `cargo run --bin check_mtgo_competitive_wiring_readiness_v1` and `cargo run --bin check_mtgo_competitive_model_decision_readiness_v1`.
